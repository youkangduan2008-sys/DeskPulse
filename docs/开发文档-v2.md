# DeskPulse v2.0 开发文档

> 版本：v2.0（界面重设计 + 功能增强）
> 日期：2026-09-27
> 基线：v1.x（desktop_widget.py 约 2490 行，Tkinter Canvas 单文件实现）

---

## 一、项目现状

DeskPulse 是 Windows 桌面悬浮卡片工具，单文件 Python（Tkinter Canvas 手绘 UI），
PyInstaller 打包为 `DeskPulse.exe`。现有能力：

| 模块 | 现状 |
|---|---|
| 时钟日历 | 每秒走时、公历、农历 + 节日，点击弹出系统日历 |
| 天气 | Open-Meteo 免费接口，城市 / 温度 / 体感 / 湿度风 / 高低温 / 降水概率，手绘天气图标 |
| 账户监控 | DeepSeek、火山方舟多账户余额 / 用量，阈值预警，设置内充值入口 |
| 交互 | 拖拽、锁定、置顶、缩放（85%–160%）、6 套主题、全局热键、右键菜单 |
| 工程 | config.json 持久化、error.log、单实例、DPI 感知 |

### 现状 UI 问题（从截图与源码确认）

1. **顶部按钮分两簇**：刷新 / 锁 / 置顶在 `W-134 ~ W-50`，关闭单独甩到 `W-22`，
   间距节奏不一致，视觉上像"5 个东西"。
2. **天气区信息过载**：5 行文字（城市 / 温度 / 体感 / 湿度风 / 高低温降水）+ 链接，
   图标仅 0.6 倍率缩在角落，温度 23px 与详情 8.5px 层级拉不开。
3. **账户卡主次不清**：余额是最重要的数字，却用 9.5px 普通字重混在文本行里；
   品牌圆点太小，"余额不足"红字直接顶在名字后面，像报错不像徽章。
4. **节奏不统一**：圆角 18/10 混用，间距凭手感（6/8/20/22），没有网格。

### 功能缺口

- 开机自启要用户手动复制快捷方式（文档第十三章），应该内置开关。
- 余额只有当前值，看不出"比上次少了多少"。
- 只有 DeepSeek / 火山方舟，国内常用的硅基流动（SiliconFlow）不支持。
- 时钟秒数不可关（有用户只想看 HH:MM，更安静）。

## 二、v2.0 预期目标

### 目标 A：界面重设计（主目标）

> 原则：**一眼看到钱和时间，其余退后。** 8px 间距网格，三级字阶，一种圆角语言。

| # | 改进项 | 验收标准 |

| A1 | 顶部按钮统一为一簇，等距 28px，靠右对齐 | 4 个圆钮视觉节奏一致，hover 反馈保留 |
| A2 | 时钟区：时间 30px 等宽体，日期农历收敛为一行辅助信息 | 3 秒外能读时间 |
| A3 | 天气区：图标放大（0.9 倍率），温度 28px 与图标并列，详情压缩为 2 行 | 信息 ≤4 行，不再拥挤 |
| A4 | 账户卡：左缘 4px 品牌色竖条；余额 15px 加粗右对齐成大数字；预警改为胶囊徽章 | 余额是卡内最大文字 |
| A5 | 统一圆角（卡片 16 / 账户块 12）与 8px 间距网格 | 全卡无"凭手感"的偏移 |

### 目标 B：功能增强

| # | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| B1 | 开机自启开关 | 设置内复选框，写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 勾选后重启生效，取消即清理注册表 |
| B2 | 余额变化对比 | 本地缓存上次余额，卡内显示 `较上次 -¥1.20`（降红升绿） | 刷新后正确显示差值，首次不显示 |


- exe 路径取 `sys.executable`（PyInstaller 冻结时）否则 `sys.argv[0]`。
- 设置窗口加复选框，保存时调用；启动时读注册表同步勾选状态。

### 4.2 B2 余额缓存

- `balance_cache.json`（与 config.json 同目录）：`{profile_id: {"balance": 13.14, "ts": ...}}`
- 每次刷新成功后写入；渲染时对比，差值 ≠0 才显示，保留 2 位小数。
- 降 = 主题 `err` 色，升 = `ok` 色（中文习惯与股票一致：这里语义是"钱变多/少"，升绿降红——按"余额"语义：升绿、降红）。

### 4.3 B3 平台适配层（Adapter Registry）

把"平台"从 if/else 硬编码改为注册表，加新平台 = 加一条配置 + 一个 fetch 函数：

```python
PLATFORMS = {
  "deepseek":    {"name": "DeepSeek", "brand": "ds",   "secret": [("api_key", "API Key")], ...},
  "volc":        {"name": "火山方舟", "brand": "volc", "secret": [("ak", "AccessKey"), ("sk", "SecretKey")], ...},
  "siliconflow": {"name": "硅基流动", "brand": "sf",   "secret": [("api_key", "API Key")], ...},
  "moonshot":    {"name": "Kimi",     "brand": "ms",   "secret": [("api_key", "API Key")], ...},
  "zhipu":       {"name": "智谱GLM",  "brand": "zp",   "secret": [("api_key", "API Key")], ...},
}
```

- 各主题新增品牌色键：`sf`（青紫 `#7C5CFC`）、`ms`（月黑蓝 `#4F6BF5`）、`zp`（智谱蓝 `#3D6FE0`）。
- **设置窗口重构**：「添加账户」不再是 DeepSeek / 火山两个按钮，改为平台下拉列表（自动读取 PLATFORMS），
  密钥字段按所选平台动态生成；每账户仍支持阈值、改名、删除、充值链接。
- **渲染统一**：所有平台归一为 {大余额行, 次级行1, 次级行2} 三行结构，`_render_*` 收敛为一个 `_render_profile`。
- 硅基流动：`balance`（总额）、`chargeBalance`（充值）、`giftBalance`（赠送）。
- Kimi：`available_balance` / `cash_balance` / `voucher_balance`（代金券）。
- 智谱：无稳定余额接口 → 显示「5 小时 Token 配额用量百分比」作为额度指示，名称后缀标注（实验）。

### 4.4 B4 秒显开关

- `show_seconds: bool` 默认 True；`_tick_clock` 按配置渲染 `%H:%M:%S` / `%H:%M`

### 4.5 UI 重排（A1–A5）

- 常量区重构：`W` 保持 340；新增 `BTN_GAP=28`、`R_CARD=16`、`R_BLOCK=12` 等
- `_redraw_buttons`：从 `W-22` 起向左等距排 4 钮（不再分两簇）
- `_build_head` 重写：左列时钟 + 合并辅助行；右列图标温度并排 + 2 行详情
- `_build_profile_block` 重写：竖条 + 名称行 + 大余额右对齐 + 次级行
- `_render_ds/_render_volc` 适配新 item 结构（`balance_big`、`sub1`、`sub2`）

## A3 新增平台：WorkBuddy 积分

- 平台注册表新增 `workbuddy`（品牌绿 `wb`，六套主题均已配色），无需填写 Key。

# 附录 B · 改 UI 的流程（2026-10-14 复盘沉淀）

改界面（卡片布局、图标、对话框控件）按这个顺序走，避免"做完才发现方向不对"：

1. **先出示样**：用 `tools/_shot.py` 渲染一版，或给出 2–3 个候选的渲染对比图，确认方向后再动产品代码。
   **被否掉的方向也要先示样**——卡片上的迷你余额曲线就是没示样直接上线，下一版又整段拆掉。
2. **改完必须看渲染结果**：排版类问题无法靠读代码发现。本轮「较上次 ±¥x」与火山方舟用量行重叠，
   就是截图时才暴露的。
3. **动外链就同步实测**：`python tools/_linkcheck.py` 跑一遍，不沿用旧值（硅基流动的两个链接
   曾长期是错的，Kimi 的域名也早已迁移）。
4. **导出类功能要核对产物**：三种导出（矢量图 / 表格 / 报告）都要实跑，断言文件非空且可解析——
   曾因方法名 `_name` 与 tkinter 基类属性重名，三种导出全部静默失败。
5. **冒烟测试后清进程**：启动过 exe 或 GUI 进程，要成对回收父进程与子进程，否则会占用
   `dist\DeskPulse.exe` 导致下次编译报"拒绝访问"。
