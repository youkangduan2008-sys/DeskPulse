# DeskPulse 桌面看板 · 使用说明（v2.0）

DeskPulse 是一款 Windows 桌面悬浮小工具，把 **时钟日历（含农历节日）、当天实时天气、多个大模型平台的余额 / 用量** 集中在一张紧凑卡片上。纯本地运行，仅在刷新数据时与官方接口通信。

v2.0 新变化：全新卡片布局（大余额右对齐、品牌色竖条、预警胶囊徽章）、支持 **硅基流动 / Kimi / 智谱GLM** 等更多平台、**余额变化对比**、**开机自启开关**、**时钟秒显开关**。

## 一、打开与关闭

- 双击桌面上的 **DeskPulse** 快捷方式即可启动（也可双击文件夹内的 `DeskPulse.exe`）。
- 关闭方式（任选其一）：点卡片右上角的 **×**；按 **Ctrl + Alt + Q**（全局）；按 **Esc**；右键菜单选「退出」。
- 拖动：在卡片空白处按住左键拖动即可改变位置，位置会自动记住。

## 二、界面一览

1. **顶部按钮簇**：刷新 / 锁定 / 置顶 / 关闭，四个圆钮等距排在右上角。
2. **头部信息栏（左右并排）**：
   - 左侧 **大时钟**（可在设置中关闭秒数）+ 日期星期农历合并行；
   - 右侧 **天气区**：大温度 + 天气图标，城市天气体感、湿度风向、今日高低温与降水概率。
3. **监控账户区**：每个平台账户一张卡片——左缘品牌色竖条、右上 **大余额数字**、下方充值/赠送明细，右侧 **「较上次 ±¥x」** 变化提示（升绿降红）。
4. 余额低于阈值时：状态点变红 + 名称旁出现红色 **「余额不足」胶囊徽章** + 大余额变红。
- 账户较多时账户区自动出现滚动条，滚轮翻页。
- 底部状态栏默认隐藏，鼠标移入卡片时浮现。

## 三、添加监控账户（支持多平台多账户）

入口：右键卡片 →「设置…」，或按 **Ctrl + Alt + S**。设置窗口底部一排平台按钮，按需添加：

| 平台 | 需要密钥 | 获取地址 | 显示内容 |
|---|---|---|---|
| DeepSeek | API Key（`sk-` 开头） | platform.deepseek.com/api_keys | 余额、充值、赠送 |
| 火山方舟 | **IAM 密钥**（`AKLT` 开头） | console.volcengine.com/iam/keymanage/ | 余额、现金/信控、今日 tokens 用量 |
| 硅基流动 | API Key | cloud.siliconflow.cn → API 密钥 | 余额、充值、赠送 |
| Kimi（Moonshot） | API Key | platform.moonshot.cn → API Key 管理 | 可用余额、现金、代金券 |
| 智谱GLM(配额) | API Key | bigmodel.cn → API Keys | Token 配额用量百分比（实验性，无公开余额接口） |
| WorkBuddy积分 | **无需密钥** | 自动读取本机桌面端登录态 | 积分余额（n 分）、连续签到天数、今日是否已签 |

- 每类平台可添加 **多个账户**；同名类型自动编号。
- 账户的添加 / 编辑 / 删除点「保存」后立即生效，主卡片实时同步。
- 编辑时密钥留空表示不修改原密钥。
- 暂不支持 OpenAI / Anthropic / MiniMax：这几家没有公开的轻量余额查询接口。

火山方舟注意：`ark-` 开头的是方舟推理 API Key，**不能**查询余额和用量，必须填 IAM 访问密钥。

WorkBuddy 积分注意：桌面端 5.6.0 起把本地登录凭据改成了加密格式，本工具不破解加密凭据，
这种情况卡片会如实提示「桌面端5.6+凭据已加密，暂不支持自动读取」；5.5.x 及更早版本可直接显示积分。

## 四、余额预警、变化对比与充值

- 「余额预警阈值（元）」填 0 表示不提醒；低于阈值即显示红色「余额不足」徽章（智谱GLM 阈值为配额用量百分比，默认 90% 预警）。
- **「较上次 ±¥x」**：每次刷新与上一次余额对比，涨绿跌红；首次添加不显示。
- **充值**：设置窗口每个账户一行，点棕色「充值」按钮自动打开对应平台官方充值页。

## 五、全局快捷键（可自定义）

| 功能 | 默认快捷键 |
|---|---|
| 打开设置 | **Ctrl + Alt + S** |
| 关闭退出 | **Ctrl + Alt + Q** |

在「设置 → 全局快捷键」中点击输入框后按下新组合键即可改键；「清除」则禁用。

## 六、配色主题（6 套柔和护眼配色）

右键 →「切换配色」循环，或在设置中选择：深夜蓝 / 墨绿护眼 / 暖可可 / 豆沙绿(浅) / 暖米黄(浅) / 雾灰蓝(浅)。
各主题的余额大数字均使用最高对比度文字色，不会被背景淹没。

## 七、界面缩放

- 按住 **Ctrl + 鼠标滚轮** 缩放（85%–160%）；或右键菜单「放大 / 缩小 / 重置缩放」。

## 八、锁定 / 置顶 / 自启

右上角四个按钮，鼠标悬停会浮出中文提示；**激活时按钮变为实心强调色**，状态一眼可辨：

| 按钮 | 说明 |
|---|---|
| 刷新数据 | 立即拉取天气与全部账户余额 |
| 锁定/解锁界面 | 锁定后防误触，仅保留解锁与退出；激活为实心 |
| 窗口置顶开关 | 默认不置顶；开启后按钮实心 |
| 关闭小工具 | 悬停变红，点击退出 |

- **开机自启**：设置中勾选「开机自动启动」即可（写入注册表 HKCU Run 键，无需管理员权限），取消勾选即清除。

## 九、点击跳转

- 点击 **左侧时钟区**：弹出 Windows 任务栏日历与时钟面板。
- 点击 **右侧天气区**：浏览器打开该城市天气预报。

## 十、天气与数据刷新

- 天气来自 Open-Meteo，免费无需 Key，每 30 分钟自动刷新；内置 130+ 中国城市坐标。
- 账户数据按「刷新间隔（分钟）」自动刷新，默认 10 分钟；右键「立即刷新」或点刷新按钮随时手动刷新。

## 十一、文件与排错

- 文件夹内容：`DeskPulse.exe`（主程序）、`config.json`（配置）、`balance_cache.json`（余额缓存，删了无影响）、`app.ico`、`desktop_widget.py`（源代码）、本说明。
- 删除 `config.json` 可恢复默认设置（账户也会清空）。
- 数据显示异常时查看同目录 `error.log`；常见原因：密钥填错（401）、网络超时、城市名无法识别。

## 十二、开机自启（手动方式，备选）

设置里的「开机自动启动」开关即可，一般无需手动。手动备选：按 `Win + R` 输入 `shell:startup` 回车，把 DeskPulse 快捷方式复制进启动文件夹。

- 右上角四个功能键在**一个圆角工具条**里等分排列，鼠标划过时左上角状态行会显示它的功能名；
  锁定 / 置顶开启后对应分段变**实心强调色**。
- 底部不再有空白带；更新时间与操作提示移到了左上角，与工具条同排。
- 设置窗口标题带版本号（如 `DeskPulse 设置 · v2.0.3`），便于确认自己跑的是哪一版。

> 升级提示：新版是单实例程序，若旧版还在运行，双击新程序只会把**旧窗口**调到前面。
> 请先在旧窗口上右键 →「退出」，再启动新版本。

## 十四、性能说明（v2.0.4）

- **空闲占用已优化到接近 0%**：界面改为「数据变化才重绘」，
  不再像旧版那样每 200ms 无脑全量刷新（这是旧版 CPU 偏高的主因）。
- **单实例检测改为端口占用**（旧版互斥量判定在 64 位下不可靠，会漏判，导致你每双击一次
  就真的多跑一个实例，CPU 成倍叠加）。
- **修掉了重复启动留下的空转进程**：单文件打包时子进程过早退出会让引导进程卡住空转
  （每个残留约 40–65% CPU）。现在重复双击只会把已运行的窗口调到最前，不会新增进程。
- 实测：单实例空闲 ≈ 0.2%（旧版在重复启动叠加后可达 100%）。

> 排错小抄：任务管理器里若曾看到多个 `DeskPulse.exe`，那是旧版的残留。
> 全部结束（右键卡片 →「退出」，必要时在任务管理器结束残留进程）后，用新版重新启动即可。

## 十五、修订记录（v2.0.5）

- **修复火山方舟卡片文字重叠**：当「今日 x 万 tokens（↑a ↓b）」这行较长时，会和右上角的
  「较上次 ±¥x」标签叠在一起。现在会按实际渲染宽度自动收缩：放不下时先在自然断点处收尾
  （例如只显示「今日 162.6万 tokens」），仍然放不下才用省略号截断。
  缩放 85%~160% 下表现一致，其他平台的卡片同样受保护。
- **重画右上角工具条图标**：刷新 / 锁定 / 置顶 / 关闭 四枚图标原本是实心块（锁体、图钉头糊成一团），
  现在全部改为描边线稿，线宽与卡片文字重量对齐，缩放下按比例取整；工具条分隔线由 14px 加长到 18px，
  不再像几根断掉的短线。

## 十六、修订记录（v2.1.0）

- **余额趋势曲线**：每次刷新把余额记进 `balance_cache.json`（最多留 200 个点，5 分钟内只更新
  最后一个点），并在每张卡片底部画一条迷你曲线。数据点少于 3 个时不画；曲线不会压到文字，
  空间不足时自动不显示。
- **余额不足系统通知**：余额从正常跌破阈值的瞬间弹一条 Windows 通知（回到正常后可再次提醒）。
  启动时已经处于预警状态的账户只记录、不打扰。不需要就别管它，或在设置里关掉。
- **自动检查更新**：每天查一次 GitHub 上有没有新版本，有就在状态行右侧显示
  「有新版本 vX.Y.Z · 点此下载」，点一下直接打开下载页；右键菜单里也有「检查更新」。
  离线、限流或访问不了 GitHub 时静默跳过，不会报错、不会卡界面。
- **新增平台：OpenRouter**：填 API Key（`sk-or-` 开头）即可显示剩余额度（美元）、累计充值与已用。
- **设置窗口的平台按钮改成两行排布**：平台数量增加后原来的一行会被窗口裁掉。
- **卡片高度由 78px 调整为 90px**，为底部的趋势曲线留出一行。

> 两个开关：`config.json` 里的 `check_update`（默认 true）和 `notify_low_balance`（默认 true），
> 改成 false 即可分别关掉自动检查和系统通知。

## 十七、修订记录（v2.2.0）

- **密钥加密存储**：`config.json` 里的密钥字段（`api_key` / `ak` / `sk`）改用 Windows DPAPI
  加密后保存，值以 `enc:` 开头。加密是当前 Windows 用户级的，换机器或换用户都解不开。
  旧配置里的明文密钥不用手工处理，下次保存时自动加密。DPAPI 不可用时自动退回明文，功能不受影响。
- **环境变量兜底**：账户没填密钥时，自动读取 `DEEPSEEK_API_KEY`、`VOLC_ACCESS_KEY_ID` /
  `VOLC_SECRET_ACCESS_KEY`、`SILICONFLOW_API_KEY`、`MOONSHOT_API_KEY`（或 `KIMI_API_KEY`）、
  `ZHIPU_API_KEY`、`OPENROUTER_API_KEY`。**环境变量来源的值不会被写进 `config.json`**，
  只有你自己在界面里填的才会落盘（且加密）。
- **少填一步**：新增账户时若环境变量里有对应密钥会自动预填并提示「已从环境变量预填」；
  设置窗口底部新增「⤓ 从环境变量导入」，一键给所有空账户补上。
- 只补空字段，绝不覆盖界面里填过的值；多账户请直接填在界面（会自动加密）。

## 十八、修订记录（v2.3.0）

- **取 Key / 充值入口校准**：硅基流动原来的两个链接是错的（`/i/account/ak`、`/i/h5/expenses`
  实测会被丢掉深路径、只回到首页），已改为 `/account/ak` 与 `/account/charge`；Kimi 的域名
  已迁到 `platform.kimi.com`，链接同步更新。
- **每个平台的「取 Key 路径」写进界面**：添加账户的窗口里现在会显示「登录后点哪几步」，
  平台改版也能照着找到；同时给出该平台最容易复制错的地方（例如智谱的 `ID.密钥` 两段式、
  火山要填两个值、`ark-` 开头查不了余额）。
- **建议单独建一把 Key**：添加账户时会提示"单独为 DeskPulse 建一把，别复用别处那把"——
  只是建议，不建也能用；好处是将来停用时只删这一把，不影响其他工具。
- **一键直达**：添加账户窗口里有「打开取 Key 页面」「打开充值页面」两个链接；右键菜单新增
  「去充值…」子菜单，直接列出你所有账户、点哪个就打开哪个平台的充值页。
- **智谱报错说人话**：智谱鉴权失败时也返回 HTTP 200、把错误藏在 JSON 里，现在会明确提示
  「平台返回：身份验证失败（智谱 Key 形如 ID.密钥 两段，检查是否整段复制）」。

> 说明：DeepSeek / 智谱 / OpenRouter 的控制台是单页应用，任意路径都返回同一个页面外壳，
> 程序无法判定深链接是否有效，所以以「文字路径」为主、直达按钮为辅。

## 十九、修订记录（v2.4.0）

- **设置界面换成自绘扁平控件**：原来的 `OptionMenu`（带 3D 边框的下拉）、系统默认复选框、
  带箭头的系统滚动条、方块按钮，在深色界面里是很旧的观感。现在统一换成自绘的：
  圆角扁平按钮、胶囊开关、带 ▾ 的扁平下拉、贴合配色的细滚动条。
- **分区标题替代 3D 边框的 LabelFrame**：改成「标题 + 副标题 + 一条细分隔线」，留白更规整。
- **账户区高度自适应**：账户少的时候不再在下面留一大块空白。
